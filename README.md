# חנות אופנה · Firebase — Fashion storefront

ברוכים הבאים. מונוריפו זה כולל את אפליקציית ה־React העיקרית תחת **`firebase/`** (אימות Firebase + Cloud Firestore, קטלוג לקוח/ניהול מנהל וכו').

## התחלה מהירה

```bash
cd firebase
npm install
npm run dev
```

פרטים מלאים: הגדרת פרויקט Firebase, משתני סביבה (`VITE_FIREBASE_*`), מבנה האוספים והערות בעברית — בקובץ **[firebase/README.md](firebase/README.md)**. העתק את **`firebase/.env.example`** ל־**`.env.local`** והזן את הערכים מהקונסול של Firebase.

---

## English

This repo hosts the **Fashion storefront** demo app under **`firebase/`** (React + Vite + Firebase Auth & Firestore).

```bash
cd firebase
npm install
npm run dev
```

See **[firebase/README.md](firebase/README.md)** for Firebase setup, env vars, and Firestore notes.
